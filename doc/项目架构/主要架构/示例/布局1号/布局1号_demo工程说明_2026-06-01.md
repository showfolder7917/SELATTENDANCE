# 布局1号 demo 工程说明

## 1. 目标

布局1号用于沉淀一套可重复复建的标准工作台形态：

- 上方英雄栏
- 左侧导航栏目
- 中间表格栏
- 右侧表单栏
- 右侧其他处理项

这套布局不是只服务某一个业务，而是作为后续 AI 和人工都可直接套用的公共页面骨架。

## 2. 工程落点

前端 demo 工程：

- `SELATTENDANCE/SELVUE/src/projects/layout1demo`

后端 demo 模块：

- `SELATTENDANCE/SELSP/src/main/java/com/sp/selfsp/layout1demo`

AI 重建提示词：

- `SELATTENDANCE/doc/项目架构/主要架构/示例/布局1号/布局1号_AI重建提示词_2026-06-01.md`

## 3. 访问方式

浏览器访问：

- `http://127.0.0.1:5180/?project=layout1demo`

后端 bootstrap 接口：

- `GET /api/layout1-demo/bootstrap`

## 4. 结构约束

布局1号固定采用以下结构：

1. 英雄栏只放页面定位、阶段说明、主题切换、语言切换和宿主 project 切换器。
2. 左栏只放模块导航、数量提醒和模块职责说明。
3. 中栏只放摘要卡、筛选栏、主表格和分页/主路径说明。
4. 右栏上半区只放当前选中记录对应的主表单或主处理动作。
5. 右栏下半区只放导入、提示词、链接、预览、联调入口等辅助处理项。

宽屏与伸缩约束也固定采用共享能力：

- 页面根壳优先复用 `shared/styles/project-entry-shell.css` 里的 `selshared-entry-page-shell--wide-workbench`
- 三栏伸缩优先复用 `shared/components/ThreePaneWorkbenchLayout.vue`
- 拖拽柄与基础分栏样式优先复用 `shared/components/ResizableWorkbenchSplit.vue`
- 禁止在布局1号里继续把左栏、主表格栏、右栏写死成固定像素宽度

## 5. 前后端契约说明

布局1号 demo 通过一个 bootstrap 接口一次性返回：

- 英雄栏数据
- 左侧导航数据
- 中栏摘要卡
- 中栏筛选默认值
- 中栏表格记录
- 右栏表单草稿
- 右栏其他处理项
- AI 提示词文档路径

这样做的目的不是追求某个具体业务真实度，而是先把“布局骨架 + 契约分层 + 前后台接线”固定下来。

## 6. 使用方式

如果后续要新建一个同类页面，优先顺序应固定为：

1. 先确认是否属于布局1号。
2. 先参照 `layout1demo` 的目录和页面结构。
3. 再按提示词文档重写业务文案、字段和接口路径。
4. 最后把 demo 里的示例数据替换成正式业务数据。

## 7. 当前注意事项

- 当前 demo 前端会优先请求真实后端 `/api/layout1-demo/bootstrap`。
- 如果本地正在运行的后端还没有刷新到最新代码，前端会回退到同结构 fallback 数据继续展示布局。
- 这种回退只用于保证布局 demo 随时可看，不等于取消正式前后台链接。
