# 布局1号 AI 重建提示词

以下提示词用于让 AI 按照当前 demo 工程稳定重建同类页面。

---

请把当前页面改造成“布局1号”。

布局1号固定要求如下：

1. 页面最上方必须是一个英雄栏。
2. 英雄栏左侧放页面阶段名、主标题、副标题。
3. 英雄栏右侧放主题切换、语言切换和宿主 project 切换入口。
4. 英雄栏下方主体必须固定成三栏：
   - 左侧导航栏目
   - 中间表格栏
   - 右侧表单栏与其他处理项
5. 左侧导航栏目只放模块列表、数量、简短职责说明，不放主表格。
6. 中间表格栏固定包含：
   - 摘要卡
   - 筛选栏
   - 主表格
7. 右侧上半区固定放主表单或当前选中记录处理动作。
8. 右侧下半区固定放 CSV 导入、提示词引用、联调入口、预览入口等辅助处理项。
9. 页面风格必须优先复用当前工程已有 shared 主题与共享英雄栏体系。
10. 宽屏页面根壳必须优先复用 shared 的宽屏工作台类，不要自己再写一个新的固定 max-width 壳。
11. 左栏、中栏、右栏的宽度关系必须优先复用 shared 三分栏与拖拽分栏能力，不要直接写死 `320px / 360px` 这类固定列宽。
10. 新代码必须优先参照以下 demo：
   - 前端：`SELATTENDANCE/SELVUE/src/projects/layout1demo`
   - 后端：`SELATTENDANCE/SELSP/src/main/java/com/sp/selfsp/layout1demo`
12. 如果要做前后台链接，优先提供一个 bootstrap 聚合接口，一次性返回：
   - 英雄栏数据
   - 左导航数据
   - 摘要卡数据
   - 筛选默认值
   - 表格数据
   - 右栏表单数据
   - 右栏其他处理项
13. 如果当前 URL 在未登录或无权限条件下实际渲染的是宿主空态，而不是业务 workbench，必须先说明实际渲染入口，再决定是否要同时改宿主空态。
14. 涉及 `js`、`java`、`py` 的新增或修改时，除 `import` 外必须补逐行业务注释。

输出时优先给我：

- 改动后的页面入口
- 关键文件路径
- 验证结果
- 如果没完全走到真实后端，要明确说明是后端未刷新、接口未启动，还是前端走了 fallback

---

一句话简写口令：

> 改成布局1号，参照 layout1demo 和它的 bootstrap 接口结构来重建。
