# SELSP Vue页面命名与目录强制规范

## 1. 文档定位

本文档用于统一 `SELATTENDANCE/SELVUE` 体系下 Vue 页面、组件、composable 和服务文件的命名与目录落点。

当前命名与目录唯一正式主参照是：

- `/Users/showfolder/Documents/workSpace/SELF/SELATTENDANCE/SELVUE/src/projects/attendance`

## 2. 页面命名规则

- 页面级组件文件使用 `PascalCase + View.vue`
- 示例：
  - `UserConsoleView.vue`
  - `DashboardView.vue`

## 3. 组件命名规则

- 可复用组件文件使用 `PascalCase.vue`
- 名称应体现业务区块或组件职责
- 示例：
  - `AppSidebar.vue`
  - `UserTable.vue`
  - `UserInspector.vue`

## 4. composable 命名规则

- composable 使用 `use + 业务语义`
- 示例：
  - `useUserDirectory.js`
  - `useUserThemePreview.js`

## 5. service 命名规则

- 服务文件使用 `xxxApi.js` 或 `request.js`
- 示例：
  - `userApi.js`
  - `request.js`

## 6. constants 命名规则

- 稳定枚举、注入键和导航定义放在 `constants/`
- 文件名使用业务语义
- 示例：
  - `userConsole.js`

## 7. 禁止事项

- 禁止把页面级组件塞进 `components/` 冒充可复用组件
- 禁止把接口访问写进 `views/`
- 禁止把跨区块状态写回单个局部组件
