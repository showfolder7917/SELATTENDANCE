# SELSP Vue新模块创建清单

## 1. 文档定位

本文档用于规范 `SELATTENDANCE/SELVUE` 新增任意 Vue 业务模块时的标准创建步骤。

当前唯一正式结构参照是：

- `/Users/showfolder/Documents/workSpace/SELF/SELATTENDANCE/SELVUE/src/projects/attendance`
- 新模块的目录、命名、i18n、shared 引用和主题接法都必须优先参照 `attendance`

## 2. 创建前检查

新增模块前必须先确认：

1. 模块名称是否稳定且不与现有模块冲突。
2. 模块边界是否清晰。
3. 是否已经明确最小输入、输出、状态和测试目标。
4. 是否已经明确该模块属于页面模块、主题模块还是通用组件模块。

## 3. 标准创建步骤

### 3.1 定义模块目标
- 明确模块解决什么问题
- 明确模块输入与输出边界

### 3.2 创建目录

默认目录结构：

```text
src/
├─ views/
├─ components/
├─ composables/
├─ services/
└─ constants/
```

### 3.3 设计状态与动作

至少明确：

- 页面主状态
- 表单状态
- 选中态
- 副作用
- 写回动作

### 3.4 设计接口接入

如果模块涉及后端：

- 先明确请求入口
- 再明确响应结构
- 再设计 service 封装

### 3.5 设计组件与布局

- 先定义页面级布局
- 再拆组件
- 再下沉到 composable 和 service

### 3.6 编写测试

至少补齐：

- 构建验证
- 页面主路径验证
- 关键交互验证

### 3.7 补充文档

新模块落地后至少补以下文档之一：

- 模块设计文档
- 实施说明
- 主题说明

## 4. 模块创建完成标准

1. 目录结构已按标准建立
2. 页面、组件、状态、服务边界清晰
3. 至少存在最小可执行验证
4. 已补项目级文档或模块说明
