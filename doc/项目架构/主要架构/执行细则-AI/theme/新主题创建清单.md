# SELTHEME 新主题创建清单

## 1. 文档定位

本文档用于规范新增任意新主题包时的标准创建步骤。

新增主题包时，唯一正式落点与参照根目录是：

- `/Users/showfolder/Documents/workSpace/SELF/SELTEMPLATE/SELTHEME`

## 2. 创建前检查

新增主题前必须先确认：

1. 主题名称是否稳定且不会和现有主题语义重叠。
2. 该需求是新主题，还是现有主题包的增强。
3. 是否已经明确最小视觉目标、组件范围、资产范围和验证目标。
4. 是否已经明确该主题是独立风格，还是现有风格的亮/暗变体。

## 3. 标准创建步骤

### 3.1 定义主题名

- 使用稳定英文名
- 明确主题主风格和适用场景

### 3.2 创建目录

默认在：

```text
themes/<theme-name>/
```

下创建：

```text
README.md
tokens.css
components.css
assets/
preview/index.html
```

若主题页需要互动 demo，再继续补：

```text
components/
components/buttons.css
components/forms.css
components/tabs.css
components/tables.css
components/trees.css
components/overlays.css
scripts/
scripts/index.js
scripts/buttons.js
scripts/forms.js
scripts/tabs.js
scripts/tables.js
scripts/trees.js
scripts/overlays.js
preview/demo.html
preview/fragments/
preview/scripts/
preview/styles/
```

### 3.3 设计 token

至少明确：

- 主背景
- 主题表面层
- 边框线
- 主文本
- 辅助文本
- 主色
- 强调色
- 圆角
- 模糊
- 阴影

### 3.4 设计组件样式

至少补齐：

- 卡片
- 主按钮或胶囊按钮
- 输入框
- 标签或状态块

若主题会作为正式样例页复用，应继续拆到：

- `buttons` 子层
- `forms` 子层
- `tabs` 子层
- `tables` 子层
- `trees` 子层
- `overlays` 子层

若主题页需要正式目录和样例映射，还应继续补：

- `scripts/index.js` 聚合入口
- 各组件子层对应的主题脚本文件
- 由主题脚本统一导出的目录元数据

### 3.5 设计资产

按需补齐：

- 背景雾化图
- 光效球体
- 网格高光
- 插图或纹理

### 3.6 编写预览页

预览页至少应展示：

- 主题名称
- 一组核心卡片
- 一组按钮
- 一组输入或表单元素

若要提供正式互动 demo，预览页还应具备：

- 稳定壳页
- 分组导航
- 样例展示区
- 可见的互动状态反馈区
- 可通过静态服务访问的 demo 入口

### 3.7 补充说明文档

至少补：

- 主题包 README
- 根目录主题说明是否需要同步更新

若 demo 不能直接 `file://` 打开，还应补：

- 根目录 `.command` 打开脚本
- README 中的启动方式说明

### 3.8 编写验证

至少补齐：

- 目录结构复核
- preview 页面访问验证
- 样式和资产相对引用验证
- 截图证据

若存在互动 demo，再补：

- 浏览器级点击或输入验证
- 启动脚本验证
- 端口回收验证
- 目录元数据与左侧导航一致性验证
- 旧前缀文本残留检索验证

## 4. 创建完成标准

1. 主题包目录已建立
2. token、组件样式、资产、preview 齐全
3. preview 可访问
4. 至少有一份可视化验证证据
5. 文档已补齐
