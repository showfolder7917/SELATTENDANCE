# SELTHEME 主题包命名与目录强制规范

## 1. 文档定位

本文档用于规定主题工程中单主题包的命名方式、目录层级和文件命名强制要求。

当前唯一正式主题包依赖根目录是：

- `/Users/showfolder/Documents/workSpace/SELF/SELTEMPLATE/SELTHEME`

## 2. 主题包命名规范

- 主题包目录统一放在 `themes/` 下。
- 主题包名使用稳定、可读、可扩展的英文或英文短语。
- 多单词主题名使用中划线连接，例如：
  - `liquid-glass`
  - `soft-dark`
  - `pearl-light`

禁止：

- 使用中文目录名作为主题包正式名
- 使用需求编号、日期、个人缩写命名主题包
- 使用 `theme1`、`new-theme` 这类临时名称

## 3. 单主题包强制目录

每个主题包至少必须具备：

```text
themes/<theme-name>/
├─ README.md
├─ tokens.css
├─ components.css
├─ assets/
└─ preview/
   └─ index.html
```

必要时可按需补充：

- `components/`
- `scripts/`
- `preview/demo.html`
- `preview/fragments/`
- `preview/scripts/`
- `preview/styles/`
- `examples/`
- `exports/`
- `docs/`

但不得缺少基础四件套：

1. `tokens.css`
2. `components.css`
3. `assets/`
4. `preview/index.html`

## 4. 文件命名规范

- 主题变量文件固定命名为 `tokens.css`
- 组件样式文件固定命名为 `components.css`
- 组件子层推荐固定命名为：
  - `components/buttons.css`
  - `components/forms.css`
  - `components/tabs.css`
  - `components/tables.css`
  - `components/trees.css`
  - `components/overlays.css`
- 主题脚本层推荐固定命名为：
  - `scripts/index.js`
  - `scripts/buttons.js`
  - `scripts/forms.js`
  - `scripts/tabs.js`
  - `scripts/tables.js`
  - `scripts/trees.js`
  - `scripts/overlays.js`
- 预览入口固定命名为 `preview/index.html`
- 正式互动壳页推荐固定命名为 `preview/demo.html`
- 资产目录固定命名为 `assets`

资产文件建议：

- 使用语义化英文名
- 使用中划线连接
- 尽量体现用途，例如：
  - `liquid-mist.svg`
  - `liquid-orb-cyan.svg`
  - `liquid-grid-glow.svg`

## 5. 引用规范

- `components.css` 应通过相对路径引用 `tokens.css`
- 若已拆子层，`components.css` 应继续作为聚合入口引用 `components/buttons.css`、`components/forms.css`、`components/tabs.css`、`components/tables.css`、`components/trees.css`、`components/overlays.css`
- 若已拆主题脚本层，`scripts/index.js` 应继续作为聚合入口统一导出主题层元数据
- `preview/index.html` 应通过相对路径引用本主题包的样式和资产
- `preview/demo.html`、`preview/fragments/`、`preview/scripts/`、`preview/styles/` 必须只通过本主题包内的相对路径互相引用
- `preview` 若依赖主题层目录数据，应通过 `../../scripts/index.js` 或等价聚合入口读取，不得手写一套独立平行目录
- 禁止 `preview` 反向引用根目录平铺文件
- 禁止一个主题包直接依赖另一个主题包内部资源

## 5.1 前缀命名统一约束

- 同一个主题包内的类名前缀、变量前缀、脚本命名和启动脚本日志前缀必须统一
- 若主题正式命名为 `seltheme`，则应统一使用 `seltheme-*`、`--seltheme-*` 等稳定前缀
- 禁止在同一主题包内长期混用 `selftheme`、`seltheme` 或其他历史前缀
- 若发生主题前缀更名，必须通过统一扫描和批量替换完成，不允许只改局部展示层

## 6. 根目录约束

- `SELTHEME` 根目录不得平铺 `tokens.css`
- `SELTHEME` 根目录不得平铺 `components.css`
- `SELTHEME` 根目录不得平铺独立主题 `preview.html`
- `SELTHEME` 根目录不得平铺主题私有资产
- `SELTHEME` 根目录若存在主题打开脚本，只允许保留 `.command` 这类启动器，不应把 preview 内容再平铺回根目录

## 7. 常见错误

禁止以下做法：

- 把所有主题都写回一个 `theme/` 目录，不区分主题包
- 只保留样式文件，不保留 preview 入口
- 进入互动 demo 阶段后，仍把全部标记、脚本和样式长期塞回一个 html
- preview 页面引用旧路径，目录移动后不修正
- 新增第二套主题时继续改第一套主题目录，而不是新建包
