# 企业级权限管理平台设计文档

## 项目目标
构建统一用户认证与权限管理平台，支持多系统接入（考勤、财务等），并具备模块化扩展能力。

## 技术栈
- 后端: Spring Boot
- 前端: Vue
- 数据库: H2

## 核心能力
- JWT 统一认证
- RBAC 权限模型
- 模块化扩展
- 模块开关控制

## 架构说明
前端通过REST API访问权限中心，获取Token后调用各业务系统。

## 数据库设计
用户、角色、权限、模块四大核心表，并通过关联表建立关系。

## 分阶段实施
1. 基础登录与权限
2. 模块化设计
3. 前端优化
4. 企业级扩展

## 总结
该平台支持多系统统一权限控制，适用于企业级应用扩展。


构建一个企业级统一权限管理平台（IAM Lite），支持：

✅ 用户统一登录（JWT / SSO）
✅ RBAC权限控制（用户-角色-权限）
✅ 模块化扩展（考勤 / 财务 / HR / 任意系统）
✅ 模块开关控制（启用/禁用）
✅ 多系统接入（可扩展）
✅ 前端动态权限控制（菜单 / 按钮）
